The suite

Three addons, one minimap menu.

01/rp

RicoPlates

Animated health bars, player and target portraits, party alerts and a cast warning that tracks spells aimed at you.

  • Combined inventory /ri
  • Mining pins, routes and skill help
  • Quest markers and map guidance
02/rl

RicoLoot

Search by zone, creature or item. Compare the available reference and observation data, and record drops as you play.

  • Searchable loot tables
  • Local loot observations
  • Item wishlist and farming goals
03/rf

RicoFishing

Look up fish and fishing areas, set a goal, and keep track of your catches without leaving the game.

  • Fishing guide and map tools
  • Catch and goal tracking
  • Shared Rico interface

Setup

Install once.
Keep it up to date.

WowUp can install and update the suite outside the game. Releases target the Forever client.

  1. Open WowUp

    Choose World of Warcraft: Forever as your game client.

  2. Install from URL

    Paste the Rico Suite repository link in Get Addons → Install from URL.

    github.com/goblindotexe-cpu/rico-suite
  3. Enable Auto Update

    Right-click Rico Suite in My Addons and enable Auto Update. Close WoW before applying an update.

To install manually, close WoW and extract the three addon folders into _forever_/Interface/AddOns.
